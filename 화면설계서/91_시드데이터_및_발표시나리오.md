## 10. 발표 시나리오 (약 7분)

각 단계는 화면설계서의 기능을 한 번씩 보여주도록 구성했다. 시연 중 실수하면 [데모 초기화]로 되돌린다.

| # | 화면 | 시연 동작 | 보여줄 포인트 |
|---|---|---|---|
| 1 | 로그인 | [계정 자동 입력] → [로그인] | 데모 계정으로 진입, 직원목록 이동 |
| 2 | 회사설정 > 근무유형 | 카드 3개 확인. [+ 근무유형 추가]로 "시차출근B"(고정 11:00~20:00, 40시간) 추가. "표준근무"의 삭제가 막혀 있음을 보여줌 | 기본 제공 보호(D18), 적용 직원 수 |
| 3 | 회사설정 > 휴일 | 2026년 법정휴일 목록. 법정 행은 삭제 불가, "창립기념일" 삭제 가능. 휴일 하나 추가(7단계 휴가 기간과 겹치지 않는 날짜, 예: 2026-12-24 "회사 휴무일") | 법정/추가 구분(D23), 휴일이 휴가 계산 원천 |
| 4 | 조직도 > 부서 | 개발팀 아래 "QA팀" 추가. 강서아를 QA팀으로 이동. 인프라팀 삭제 시도 → 소속 직원 있어 막힘 | 트리, 이동, 삭제 차단(M8) |
| 5 | 조직도 > 직책/직위 | 직위에 "인턴" 추가 후 저장. 사용 중인 "사원" 삭제 시 경고 확인 → 취소 | 일괄 저장, 사용 인원 경고(D19) |
| 6 | 직원등록 | [+ 직원 등록]으로 새 직원 입력(필수 항목 비움 → 오류 확인 후 입력). 목록에서 부서별·검색 필터 시연. 한도윤 상세 → [삭제] 비활성(휴가 기록 있음). 장수빈은 퇴사 상태 확인 | 입력 검증, 필터, 삭제 규칙 |
| 7 | 휴가 > 휴가현황·등록 | 서지민 연차 2026-10-08 ~ 10-12 등록 → 사용일수 **2일**(한글날·주말 제외) 표시. 이어서 신유나 연차 2026-11-02 ~ 11-17 → 사용 12일, 잔여 부족 경고 후 등록(잔여 −1 확인). 등록된 휴가 하나 [취소] | 주말·휴일 제외 계산, 잔여 초과 경고, 취소 |
| 8 | 휴가 > 휴가부여 | 신유나 행에서 신규휴가 `1` → [부여]. 값 `0.3` 입력 시 오류. 잔여가 음수에서 바뀌는 것 확인 | 수동 부여, 0.5 단위 검증, 사용·잔여 반영 |
| 9 | 마무리 | [데모 초기화] → 확인 → 시드 상태로 복귀 | 발표 반복 가능 |
